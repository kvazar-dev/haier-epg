# haier-epg — программа передач для Haier S7 (Google TV 14)

Гид в стиле Samsung для телевизора Haier S7 65" (Haier MatrixTV AEL, HRT51EUL, MediaTek mt5889): слева
список каналов, справа сетка программ по времени, 12 каналов на страницу, переключение канала только по OK,
планирование переключения на будущую передачу с подсказкой за 20 секунд до начала.

Приложение не содержит своего видеоплеера: канал переключает штатное Live TV прошивки
(`com.mediatek.wwtv.tvcenter`), которому гид отдаёт URI канала. Данные берутся из системной базы Android
TvContract, куда тюнер MediaTek пишет каналы и расписание. Без интернета, без фоновых служб; один точный
будильник на каждую запланированную передачу.

Собрано как дополнение к [cleanyourtv](https://github.com/Gathin23/cleanyourtv): там лежит лансер, который
открывает этот гид по кнопке программы передач на пульте (`app_keys`: `172:dev.kvazar.epg`).

## Управление

| Кнопка | Действие |
|---|---|
| Вверх / Вниз | канал выше / ниже (время сохраняется) |
| Влево / Вправо | предыдущая / следующая передача; окно времени сдвигается само |
| Каналы ± (Page Up/Down) | страница из 12 каналов |
| Перемотка ◀◀ / ▶▶ | окно времени на 3 часа назад / вперёд |
| Цифры | переход к каналу с этим номером |
| OK на текущей или прошедшей передаче | переключить канал и закрыть гид |
| OK на будущей передаче | запланировать переключение (или снять, если уже запланировано) |
| Назад, кнопка гида | закрыть |

Запланированная передача помечена ⏰. За 20 секунд до её начала появляется подсказка «Начинается…» с
обратным отсчётом 15 секунд: OK или молчание переключают канал, «Отмена» или Назад оставляют всё как есть.

## Сборка и установка

Нужны JDK 17 и Android SDK (platform 34). Из корня проекта:

```powershell
$env:JAVA_HOME = '<путь к JDK 17>'
.\gradlew.bat assembleRelease
```

APK: `app\build\outputs\apk\release\app-release.apk` (около 35 КБ, подписан debug-ключом, ставится поверх
себя). Установка и разрешения, через ADB (или `tools\tv.py` из cleanyourtv):

```
adb install -r app-release.apk
adb shell pm grant dev.kvazar.epg android.permission.READ_TV_LISTINGS
adb shell appops set dev.kvazar.epg SYSTEM_ALERT_WINDOW allow
```

- `READ_TV_LISTINGS` на этой прошивке имеет уровень `dangerous`: без `pm grant` приложение само покажет
  системный запрос при первом запуске.
- `SYSTEM_ALERT_WINDOW` нужно только для запланированных переключений: Android 10+ не даёт открыть окно из
  фона без него, а у телевизора нет экрана настроек, где это включается с пульта.

Проверено на Haier MatrixTV AEL, Google TV 14, прошивка UKNV.260720.004, 8 ноября 2026.

## Ограничения

- Расписание есть только у тех каналов, чей мультиплекс тюнер уже слушал: DVB-T2 передаёт EIT своего
  мультиплекса, второй заполняется, когда телевизор постоит на одном из его каналов.
- Текущий канал гид знает только после первого переключения через него: сторонним приложениям Android не
  сообщает, что сейчас показывает Live TV.
- Скриншоты гида поверх Live TV пустые: видеослой защищён. Это особенность телевизора, не приложения.
